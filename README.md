# 🦖 Dinopedia - The Ultimate Prehistoric Knowledge Portal

A modern, interactive encyclopedia of prehistoric life, dinosaurs, fossils, and excavations. Built with React, Vite, and PHP.

## ✨ Features

- 🦕 **Interactive Dinosaur Archives**: Explore specimens from the Triassic, Jurassic, and Cretaceous periods.
- 🎮 **Prehistoric Entertainment**: T-Rex Hangman, prehistoric trivia quizzes, and dinosaur simulation games.
- 🔍 **Fossil Discoveries**: Global excavation maps, paleontological research disciplines, and specimen details.
- ⚖️ **Species Compare**: Side-by-side comparative analysis of size, diet, era, and biome characteristics.
- 🔐 **Explorer ID Auth**: Seamless user session management and profile customization.

---

## 🛠️ Tech Stack

- **Frontend**: React, Lucide Icons, Vanilla CSS Design System, Vite
- **Backend API**: PHP, MySQL / MariaDB (XAMPP environment)
- **Design Tokens**: Amber / Prehistoric earth-tone glassmorphic palette

---

## 🚀 Getting Started

1. Start Apache & MySQL in **XAMPP Control Panel**.
2. Navigate to `frontend/`:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173` or access via `http://localhost/dinopedia`.
